# زهرة الربيع - نظام طلبات الجملة المباشر

منصة احترافية مخصصة لتجار الجملة لطلب ملابس الأطفال التقليدية الجزائرية.

## المميزات
- **واجهة مستخدم احترافية**: تصميم عصري يدعم اللغة العربية (RTL).
- **نظام بحث ذكي**: إمكانية البحث عن الموديلات بالاسم أو الوصف مع اقتراحات فورية.
- **إدارة كميات متقدمة**: دعم كامل للمقاسات والألوان المختلفة لكل موديل.
- **مراجعة الطلب**: ملخص شامل للطلبية قبل التأكيد النهائي.
- **متوافق مع الجوال**: تجربة مستخدم سلسة على جميع الأجهزة.

## التقنيات المستخدمة
- **Next.js 15 (App Router)**
- **Supabase Auth & SSR**
- **TypeScript**
- **Tailwind CSS**

## إعداد قاعدة البيانات والتوثيق (Supabase)

1. قم بإنشاء مشروع جديد على [Supabase](https://supabase.com).
2. انسخ `URL` و `Anon Key` من إعدادات المشروع (API).
3. قم بتعيين المتغيرات التالية في ملف `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your-project-url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   ```
4. قم بتمويل جدول المستخدمين عبر Supabase Auth لإضافة حسابات المسؤولين.

## هيكلة المشروع
- `src/features/auth`: نظام التوثيق والحماية.
- `src/features/order-system`: نظام الطلبات الأساسي.
- `src/lib/supabase`: أدوات الاتصال بـ Supabase.
- `src/middleware.ts`: حماية المسارات (Admin Protection).

## التشغيل محلياً

1. قم بتثبيت التبعيات:
   ```bash
   npm install
   ```

2. ابدأ خادم التطوير:
   ```bash
   npm run dev
   ```

3. لبناء المشروع للإنتاج:
   ```bash
   npm run build
   ```
